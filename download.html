Reassemble the ISO

cat sigmaos-desktop-2026.11.24-x86_64.iso.part* > sigmaos-desktop-2026.11.24-x86_64.iso
sha256sum -c sigmaos-desktop-2026.11.24-x86_64.iso.sha256

Write to USB

sudo dd if=sigmaos-desktop-2026.11.24-x86_64.iso of=/dev/sdX bs=4M status=progress oflag=sync

Warning: replace /dev/sdX with your USB device — this erases it.

Try in QEMU

qemu-system-x86_64 -m 4G -enable-kvm -cdrom sigmaos-desktop-2026.11.24-x86_64.iso

Or with VNC for headless testing:

qemu-system-x86_64 -m 4G -enable-kvm -cdrom sigmaos-desktop-2026.11.24-x86_64.iso -vnc :1

UEFI test (needs ovmf installed):

qemu-system-x86_64 -m 4G -enable-kvm \
  -drive if=pflash,format=raw,readonly=on,file=/usr/share/OVMF/OVMF_CODE_4M.fd \
  -drive if=pflash,format=raw,file=OVMF_VARS.fd \
  -cdrom sigmaos-desktop-2026.11.24-x86_64.iso -boot d

  • Releases before 2026.11.24 have broken UEFI — use this release. The -uefi and -run28 tags are superseded by -run32.
  • Full install (sigmaos-install --destructive) is experimental; dry-run is safety-tested.
  • Snapshot/rollback is not yet implemented — don't rely on it.
  • Recovery: sigmaos-theme reset restores defaults; sigmaos-doctor (SUPER+/) diagnoses problems.
